# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its Code of
Conduct. The full canonical text is published here:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — issues, pull requests, discussions, Discord,
or any other community space — you agree to uphold that standard.

## In short

- Be respectful, welcoming, and considerate.
- Assume good intent; give and accept constructive feedback gracefully.
- No harassment, discrimination, or personal attacks of any kind.
- Focus on what is best for the community and the project.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the
maintainers:

- Discord: message a `team`-role member in the StacyOS server (`#dev`).
- GitHub: contact a maintainer directly, or for sensitive matters use the
  Security Advisory channel described in [`SECURITY.md`](SECURITY.md).

All reports are reviewed and handled confidentially. Maintainers are obligated
to respect the privacy and safety of anyone reporting an incident.

## Enforcement

Maintainers are responsible for clarifying and enforcing this standard and may
take any action they deem appropriate, up to and including a temporary or
permanent ban from project spaces, in response to behavior that violates it.
Enforcement follows the guidelines in the Contributor Covenant 2.1 linked
above.
