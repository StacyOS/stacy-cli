# v2026.523.0

> Release date: 2026-05-23
> Status: Draft

## Summary

- Adds product-readiness layers on top of the public federation demo substrate:
  minimal UI read surface, write-scope derived KOs, two-machine HTTPS preflight,
  and multiple adapter output contracts.
- Keeps the original public demo path intact: dashboard KOs remain the default,
  and the create -> share -> read -> revoke -> deny loop still runs under the
  4-minute bar.
- Extends `stacy run "<task>" --input <csv>` beyond dashboards with
  `--output-kind report` and `--output-kind table`, while preserving signed KO
  provenance and adapter guardrails.

## Changes

### Added

- Federation Brain UI route for inspecting a KO from the browser:
  - `GET /api/federation/brain/:koId`
  - `/federation/brain/:koId`
- Write-scope consent support for derived Knowledge Objects.
- `stacy brain derive <source_ko_id> --content-json <json>` for consumers with
  write/admin consent to create a signed derived KO that references the source
  KO, source hash, grant, producer install, and consumer install.
- `derive` federation receipt event.
- Two-machine deployment preflight:
  - `pnpm --filter @arpanstacy/stacy-federation demo:remote:preflight`
  - HTTPS-required remote URL checks, with explicit self-signed-cert opt-in for
    controlled demos.
- Adapter output kind selection:
  - `stacy run "<task>" --input <csv> --output-kind dashboard`
  - `stacy run "<task>" --input <csv> --output-kind report`
  - `stacy run "<task>" --input <csv> --output-kind table`
- Schema-validated adapter JSON contracts for dashboard, report, and table KOs.
- Deterministic offline report/table fallback content when no adapter is used.

### Changed

- Consent grant scopes now support `read`, `write`, and reserved `admin`.
- Read-time consent enforcement treats `write` and `admin` as read-capable for
  display, while derived KO creation requires write/admin capability.
- `brain show` renders derived KO provenance in text output.
- Public demo documentation now includes UI inspection, write-scope derivation,
  remote HTTPS preflight, and report/table adapter examples.
- Adapter stdin now includes `outputKind` so external adapters can choose the
  correct output contract.

## Breaking Changes

- None known. Dashboard remains the default `stacy run` output kind.

## Known Limitations

- The new UI is intentionally minimal and read-focused.
- Write scope creates a derived KO; it does not mutate the producer's original
  KO in place.
- Remote federation preflight validates deployment prerequisites but does not
  provide NAT traversal or certificate provisioning.
