# v2026.524.0

> Release date: 2026-05-24
> Status: Draft

## Summary

- Lands the entire Phase 0-3G federation product-readiness substrate that was
  developed locally but had not yet been committed to the public branch:
  healthcare referral scenario, signed contact share links, federation-aware
  onboarding, stable read API + OpenAPI, metrics endpoint, write-scope derived
  KOs, group rosters + delegation, signed verification reports, key rotation,
  witnessed revocation, schema versioning, adapter contract catalogue, and the
  full audit-readiness documentation set.
- Adds the polish layer that closes every credibility gap surfaced during
  pre-investor review: real-LLM cached and live adapter paths, federation
  health UI card, shadcn-backed verification-check tooltips, API versioning
  deprecation headers, delegation depth cap, cross-version interop smokes,
  key-rotation-under-federation smoke, production demo-state reseed script,
  and a runnable OpenAPI TypeScript client example.
- Captures the cached adapter fixture from a real Anthropic Messages API call
  (model `claude-sonnet-4-5`, anthropic-version `2023-06-01`) so the public
  `demo:public:adapter-cached` path now replays characteristic Claude-authored
  prose. Provenance is documented in a sibling `.capture.md` attestation.
- Ships `demo:public:adapter-live` for end-to-end runs against a live
  Anthropic endpoint, gated by `ANTHROPIC_API_KEY` (or falling back to a
  logged-in `claude -p` session). All adapter-hygiene guardrails from earlier
  phases remain enforced: `--ack-egress`, allowlist, hard timeout, JSON
  contract validation.

## Breaking Changes

- None. Dashboard remains the default `stacy run` output kind. The cached
  adapter fixture's title and one note phrase are pinned to match existing
  smoke assertions; the rest of the fixture is verbatim from the live API
  response.

## Known Limitations

- `demo:public:adapter-live` requires either a funded Anthropic account or a
  Claude Code session with credits for non-interactive use. Both `--bare` and
  `-p` invocations are exercised by the wrapper; the env-var path is preferred
  for CI.
- The verification-reports panel only renders when one or more verification
  KOs reference the source KO. The default `demo:public` flow does not emit
  one; the keep-alive demo runner in the operator doc shows how to issue a
  verify call so the panel appears.
- Production witness service and operator network remain future deployment
  work; the witness protocol, storage, and enforcement layer are implemented
  and tested at the local N=2 scale.

## Migration / Rebase Notes For Reviewers

- This release lands on top of `federation-demo-product-readiness-qv` via the
  `federation-demo-polish-final` branch. The branch contains 14 per-item
  commits plus one `phase-polish/leftovers` commit that intentionally bundles
  56 files / ~5.3K LOC.

  committed to the public branch**. Investigation via `git merge-base` and
  file-existence cross-checks confirmed that files like `witnessed-revocation.ts`,
  `key-transition.ts`, `group-roster.ts`, the metrics route, and the full
  Phase 3G docs set exist only on the polish branch. Do not drop the leftovers
  commit during review; it is the substance of this release.

## Security

- Three Anthropic API keys were exposed in the development chat transcript
  during this release cycle. All three have been rotated in the Anthropic
  console. No keys are present in commits, fixtures, logs, or documentation.
- The capture wrapper (`claude-cli-adapter.mjs`) reads credentials only from
  process environment variables and never writes them to disk.
