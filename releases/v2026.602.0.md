# v2026.602.0

> Release date: 2026-06-02
> Status: Draft (v0.2 alpha — awaiting external-credential validation per `PHASE-2-HANDOFF.md`)

## Summary

- Ships the **v0.2 alpha: connectors + AI runs** layer on top of the v0.1 local
  Knowledge Object surface. Two new capabilities: **connectors** that pull
  external data (GitHub first) into signed Knowledge Objects, and **AI runs**
  that take those KOs as context and produce a new signed `agent_output` KO.
  Everything stays local-first — nothing leaves the install unless the operator
  explicitly acknowledges egress.
- Adds the **GitHub connector** (OAuth device-code flow, AES-256-GCM
  encrypted-at-rest token storage, sliding-window rate limiting) and the
  `stacy connect` / `connectors list|status|disconnect` / `ingest` verbs that
  turn GitHub pull requests and issues into signed KOs with connector
  provenance and `ingest` + `normalize` receipts.
- Adds `stacy run "task" --use <ko_id>` AI runs that verify every input KO, gate
  egress before any read, and sign a new `agent_output` KO whose provenance
  lists its inputs. Ships `deterministic` (offline) and `anthropic` run
  adapters, plus a **run-result cache** so identical runs skip the billable
  adapter call.
- Adds operator-facing docs: a v0.2 quickstart, connector + AI-run concept docs,
  a GitHub connector guide, a full **CLI reference**, and an engineer
  **handoff doc** describing the external credentials needed to validate the
  live paths.

## Changes

### Added — GitHub connector

- GitHub connector: OAuth device-code flow, encrypted-at-rest token storage,
  sliding-window rate limiting, normalize pipeline for pull requests and issues
  (`packages/federation/src/connectors/github/`).
- New verbs (`packages/federation/verbs/`):
  - `stacy connect github` — device-code OAuth, stores an encrypted token under
    `<instance>/secrets/connector-tokens.json` (mode 0600).
  - `stacy connectors list|status|disconnect` — connection management; `status`
    makes a live call and refreshes a near-expiry token.
  - `stacy ingest github --repo <owner/name>` — fetch + normalize + store as
    signed KOs, with a pre-write confirmation summary (`--yes` to skip).
- Receipt chain extended with `ingest` and `normalize` events.

### Added — AI runs

- `stacy run "task" --use <ko_id>` (repeatable `--use`) — verifies and loads each
  input KO, runs the selected adapter, and signs a new `agent_output` KO with
  full input provenance. Receipt chain extended with the `run` event.
- Run adapters (`packages/federation/src/runs/adapters.ts`):
  - `deterministic` — offline, no network, no egress acknowledgement required.
  - `anthropic` (default) — shells out to `STACY_ANTHROPIC_ADAPTER_COMMAND`;
    leaves the install, so requires `--ack-egress`. The egress gate fires before
    any KO is read.
- Run-result cache (`packages/federation/src/runs/run-cache.ts`): file-backed
  under `<instance>/runs/cache`, keyed on task + model + adapter + sorted input
  content hashes (order-independent). `--no-cache` bypasses it.
- `agent_output` KO content envelope (`schemaVersion 1`) with input provenance.

### Added — reference adapter & docs

- `scripts/anthropic-run-adapter.mjs` — dependency-free reference adapter that
  implements the `STACY_ANTHROPIC_ADAPTER_COMMAND` contract, calls the live
  Anthropic Messages API, reads `ANTHROPIC_API_KEY` from its own environment,
  and strips markdown fences from model JSON. Verified end-to-end against the
  real API.
- `docs/cli-reference.md` — full v0.2 CLI surface reference.
- `docs/v0.2-connectors-and-runs-quickstart.md`, `docs/concepts/connectors.md`,
  `docs/concepts/ai-runs.md`, `docs/connectors/github.md`.
- `PHASE-2-HANDOFF.md` — engineer handoff: external credentials, test plan, and
  known limits for live validation.
- Env-gated live-Anthropic integration test
  (`packages/federation/src/runs/anthropic-adapter.live.test.ts`), skipped
  unless `STACY_ANTHROPIC_ADAPTER_COMMAND` is set.

### Changed

- `stacy run` now routes to the AI-run path when at least one `--use` flag is
  present; without `--use` it performs the existing local bootstrap
  (onboard + doctor). `--no-cache` added to the run command.
- Connector token reads now refresh near-expiry tokens (with skew) and re-store
  them, wired into `ingest` and `connectors status`.

## Breaking Changes

- None. `stacy run` without `--use` behaves exactly as before.

## Known Limitations

- v0.2 is an **alpha**. The GitHub OAuth app (with Device Flow enabled) and an
  Anthropic adapter command are operator-provided; see `PHASE-2-HANDOFF.md`.
- The `anthropic` adapter never calls the API directly — it spawns
  `STACY_ANTHROPIC_ADAPTER_COMMAND`, which must be a single executable path
  (Stacy does not shell-split; `node script.mjs` will not work).

## Security

- An Anthropic API key was exposed in the development chat transcript during this
  release cycle. The key owner has been advised to revoke it in the Anthropic
  console; it must be treated as compromised until revoked. No keys are present
  in commits, fixtures, logs, or documentation.
- `scripts/anthropic-run-adapter.mjs` reads credentials only from process
  environment variables and never writes them to disk. Stacy itself never reads,
  stores, or logs the key — it only spawns the adapter command.
- Connector tokens are stored AES-256-GCM encrypted at rest (mode 0600); they are
  never written to config in plaintext.
