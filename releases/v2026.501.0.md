# v2026.501.0

> Release date: 2026-05-01
> Status: Ready

## Summary

- Stacy Phase 5 distribution and self-hosted operations cleanup.
- Adds the public `stacy` CLI path, guarded release tooling, Docker quickstart
  verification, backup/restore flows, upgrade preflights, and the `stacy-cli`
  wrapper package path.
- Hardens the execution kernel, local adapter failure classification, and
  run/cost visibility needed before a public registry flip.

## Operator Notes

- Run the upgrade preflight before changing the instance:

```bash
pnpm stacy upgrade:check --strict
```

- Create a fresh database backup before deploying:

```bash
pnpm stacy db:backup
```

- For Docker/self-hosted instances, stop the app before applying a restore:

```bash
docker compose -f docker/docker-compose.quickstart.yml down
pnpm stacy db:restore --latest --dry-run
pnpm stacy db:restore --latest --yes
docker compose -f docker/docker-compose.quickstart.yml up -d
```

## Changes

### Added

- `stacy` binary alias alongside the existing `paperclipai` CLI.
- `stacy-cli` wrapper package for `npx stacy-cli onboard`.
- Phase 5 release gate, package-name preflight, wrapper publish helper, npm
  wrapper smoke, and release notes scaffolding.
- Self-hosted operations guide covering upgrade checks, backup, restore,
  Docker quickstart, and release checklist flows.
- Non-billable local Codex/Claude adapter preflight profiles.
- Database restore and upgrade-check CLI commands.
- Docker quickstart smoke with persistent-state restart verification.

### Changed

- Root README and public CLI docs now lead with Stacy-branded commands while
  keeping `paperclipai` as the compatibility package.
- Public dependency overrides were refreshed for the release candidate,
  including patched Vite, Rollup, PostCSS, Hono, Kysely, uuid, and esbuild
  lines.
- UI production builds now target modern ES output for the local/self-hosted
  operator console.
- `stacy-cli` uses the workspace package locally and stages a publishable
  package that depends on the matching released `paperclipai` version.
- The wrapper publish helper can dry-run without npm auth; real publish and
  deprecation still require OTP or a granular npm token with 2FA bypass.

### Fixed

- Run finalization now records cost/runtime state before terminal run timeline
  events are surfaced.
- Local adapter stale-session fallback, transcript parsing, and shared failure
  taxonomy coverage were hardened.
- Stacy/Paperclip environment aliases are normalized across CLI, server, and
  adapter utilities.

## Rollback

- Restore the previous image/package version.
- Restore the latest known-good database backup if migrations or data changes need reversal.
- Re-run `pnpm stacy upgrade:check` after rollback.

## Known Limitations

- `stacy-cli@0.3.1` is only a reserved package-name wrapper and should be
  deprecated after the matching corrected wrapper is live.
- The exact `npx stacy onboard` package remains blocked because `stacy` is
  already owned on npm.
- `pnpm audit --prod --audit-level low` still reports npm advisory
  `GHSA-6cpc-mj5c-m9rq` against package label `cli` with no dependency path.
